# 小克剪辑 · Remotion 复刻

用 [Remotion](https://remotion.dev) 以纯代码复刻的 30 秒手绘风「视频剪辑软件操作录屏」动效：一只橘色小狗「小克」在 30 秒里从打开工程、拖入素材、加转场、加字幕、拉满参数，到导出收工的全过程。

- 分辨率 1280×720，30fps，总时长 30 秒（900 帧）
- 画面全部由 SVG / CSS 手绘生成，未使用原视频任何帧素材
- BGM 与音效由 `scripts/make-audio.mjs` 无依赖合成（120 BPM，含 21.4s 的 BONK 重击与收工琶音）

## 快速开始

```bash
npm install
```

渲染成品视频：

```bash
npm run render          # 输出 out/xiaoke-edit.mp4（1280x720 / 30fps / 约 30s）
```

本地实时预览：

```bash
npm run dev             # Remotion Studio，可逐帧拖动检查
```

重新生成 BGM（可选）：

```bash
npm run audio           # 纯 JS 合成 → public/bgm.wav
```

## 代码结构

```
src/
  index.jsx                 注册入口
  Root.jsx                  Composition 定义（Xiaoke, 900 帧）
  Main.jsx                  总编排：场景节奏 / 狗勾路径 / 光标 / 各图层
  theme.js                  配色、字体、版面常数
  beats.js                  全片节拍表（所有时间节点的唯一事实来源）
  components/
    Boot.jsx                开机画面（手机虚影 + 进度卡）
    Chrome.jsx              应用窗口、顶栏、时间码、手机外壳
    LeftPanel.jsx           左侧「素材 / 转场 / 文字」面板
    AdjustPanel.jsx         右侧「调整」滑杆，驱动手机画面 filter
    Timeline.jsx            时间轴：标尺、播放头、片段落轨、音频波形
    PhoneScenes.jsx         手机内四段素材画面（夜景 / 吃面 / 聚犬 / 蹦迪）
    Dog.jsx                 小克本体 + 语音气泡
    Annotations.jsx         手写红字标注、10倍速、BONK、Ctrl+Z、已修好印章、前方高能横幅
    Finale.jsx              收尾：便签纸、点赞栏、拿捏了、彩带
scripts/
  make-audio.mjs            音频合成（无外部依赖）
```

时间相关的行为都集中在 `src/beats.js`，改节奏只动这一个文件。
